# gliksbot.com — DexterGliksbot LLC public site

Source of truth for the [gliksbot.com](https://gliksbot.com) landing page (`index.html`).

**Audience:** cloud/GPU startup-program reviewers (Google, AWS, NVIDIA, Oracle, Microsoft, Cloudflare, RunPod) and pre-seed angel investors.

**Deploy:** the site is served through a Cloudflare tunnel; sync `index.html` into the tunnel web root to publish. Recommended next step: move to Cloudflare Pages connected to this repo so `git push` auto-deploys.

**Campaign tracking:** all capital-campaign work (cloud credit applications, angel outreach) is tracked in this repo's [Issues](../../issues).
